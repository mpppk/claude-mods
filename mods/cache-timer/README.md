# cache-timer

Claude Code のプロンプトキャッシュがあと何分温かいかを、セッションごとにステータス行へ小さく表示する mod です。

```
cache 4m      ← 残り 4 分以上
cache <1m     ← 残り 1 分未満
cache cold    ← 期限切れ（次のリクエストはキャッシュを書き直す）
```

キャッシュを使った最初のリクエストまでは何も表示しません。表示は 5 秒ごとに見直しますが、文言が変わったときだけ書き換えるので、画面がちらつくことはありません。

## しくみ

- **起点**: メインスレッドのモデルリクエスト（`turn.step`）がキャッシュを読むか書くたびに、そのリクエストの送信時刻から TTL を数え直します。サブエージェントのリクエストは別のキャッシュなので数えません。
- **TTL の決め方**（設定 `ttl` が `auto` のとき）
  1. Claude Code 自身が教えてくれる値: モデル切替時の `cache_ttl`、再開時（`--resume`）の「前回応答からの経過秒数」と「キャッシュ切れ見込み」から推定
  2. 実際のキャッシュの振る舞い: 前回から 5 分〜1 時間あいたリクエストが、前回のプロンプトをほぼ丸ごとキャッシュから読めていれば 1h、共有部分（システムプロンプト等）しか読めていなければ 5m
  3. 上で学んだ値は `$.store` に保存し、次のセッションでも使います。何も分からないうちは 5m とみなします。
- **リセット**: `/clear` で表示を消し、モデル切替後は `cache cold` にします。

残り時間はあくまで推定です。Claude Code の外（API 側の都合）でキャッシュが先に消えることもあります。

## 設定

| キー | 値 | 既定 |
| --- | --- | --- |
| `ttl` | `auto` / `5m` / `1h` | `auto` |

`/config` の行から変えられます。`5m` か `1h` に固定すると学習はしません。

## 開発

```bash
../../scripts/check.sh cache-timer
```
